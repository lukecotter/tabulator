11 · Popup Positioning

A popup opened near an edge has to be moved back on screen. This page lets you drive that: pick a popup size, scroll the page so the target sits against a viewport edge, then right-click a cell. The readout shows where the popup actually landed and whether any of it fell outside the viewport. ← back to index

  • Reversal — a popup that would overflow the right edge flips to the other side of its anchor.
  • Clamping — if it is wider or taller than the space it flipped into, it is pulled back to the edge.
  • Scrolling — bounds are the visible viewport, so they move with the page scroll.
  • Containers — a popup hosted in a scrollable element is bounded by that element instead.

A popup is positioned once, in page coordinates, and then moves with the page.
